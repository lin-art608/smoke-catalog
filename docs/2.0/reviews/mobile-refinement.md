## 完成内容

1. 主站改为暖纸底色、墨色正文、朱砂强调，地图保留低饱和省界。
2. 去除地图说明、地图文字、省份文字标记及矩形点按框；地图来源移入“关于”，键盘仍可操作。
3. 手机省份入口四列、57px高；仅显示省名和居中轮廓，去除英文、数量与资料待补提示。
4. 顶部仅保留“烟标”，品牌返回地图；收藏和关于放到页脚；移除旧版入口链接。
5. 省内恢复人物剪影与烟盒并排，第一次点击人物揭示、再次进入详情；烟盒和名称也可直接进入详情。
6. 增加直接“看立绘”操作，保留放大、原尺寸和关闭；详情声明可展开。爱心居中在44px触控区，收藏跨刷新保留。
7. 针对宽幅包装照片的留白调整显示比例，不修改素材；页面脚本和样式添加版本参数以避免旧缓存。
