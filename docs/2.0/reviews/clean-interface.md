# 界面精简与省份强化 · 2026-10-17

按用户最新要求：顶部依次为烟标、排行榜、收藏；页脚仅保留关于。排行榜统一为累计人气，不显示日期分类、参与人数、介绍或计算规则，规则移至关于中的折叠项。空榜显示“暂无点赞”，不造数据。

省份背景将原配色向地域强调色混合26%，背景纹样透明度从0.17提高至约0.33，扩大省份标题留白；保留现有立绘与冻结素材。

详情人物右上角仅放爱心图标，支持真实点赞与取消；移除原框式按钮、每日一票提示、跳转排行榜、放大看立绘、向下看烟盒等文案。出错时保留必要的反馈。

立绘直接点开白底图片查看，只保留原尺寸和关闭。原尺寸在同一白底窗口查看PNG，删除2倍放大及底部描述。烟盒图可直接点开，中华软优先打开现有实拍原图，其他保留已有原图；未伪造高清。实拍来源移至详情折叠声明，不再在图片旁堆放文字。图片许可提示不在卡片和对象台上反复显示，原资料与声明仍可查。
