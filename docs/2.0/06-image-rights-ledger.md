# 图片清晰度与授权台账

完整逐件台账见`data/2.0/image-rights-ledger.json`，共126条，保留原来源URL、原访问日期、文件路径、质量声明与许可声明。

当前所有条目均`hdVerified=false`、`publicReplacementAllowed=false`。原有缩略图不能因为放大、转换WebP或AI超分而升级为高清实物照片；未知许可不能因在旧站使用过就视为已授权。

六件原型只在本机内部评审，界面持续显示“参考图 · 许可待确认”。照片不裁去警示文字，不重绘品牌小字，不用生成内容伪装实物细节。当前没有新下载图片、取得授权或完成新的实物摄影。

后续流程：核对来源权利人及许可用途 → 取得适用使用许可或自摄 → 保留原片与证明 → 校正透视及生成多尺寸 → 人工核对可读文字与完整边界 → 更新台账 → 才能公开替换。3D需要足够且有权使用的多面纹理，当前阶段不进入。
