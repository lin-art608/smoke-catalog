# 当前展示路径

地图首页（view=home）→省份展厅（view=regions&region=省份ID）→烟标/角色卡片→详情。首页仅放地图与省份入口，省份页仅放省内作品，避免混排。

全局索引126件提供组合筛选与分页；角色墙提供搜索与分批展开；收藏/专题/关于/设计记忆独立。下方保留G1/G2历史设计说明，当前实现以本段及reviews/G6.md为准。

# 页面树与路径

| 页面 | URL参数 | 主要内容 | 后续操作 |
| --- | --- | --- | --- |
| 首页 | view=home | 本期展品、地域入口、策展专题 | 进展品、按地域漫游 |
| 地区展厅 | view=regions&region=shanghai | 地图与地区按钮同步、包装展签 | 进入展品 |
| 烟标索引 | view=labels | 六件包装、主题筛选、陈列密度 | 进入展品 |
| 角色墙 | view=characters | v1剪影占位与v2候选方向 | 首次揭示、再次入详情、直接看图 |
| 展品详情 | view=detail&item=SKU_ID | 观察、解读、转译、虚构、来源、相关展品 | 包装放大、收藏、继续浏览 |
| 专题 | view=themes | 建筑的回声、印刷的秩序 | 进入关联作品 |
| 设计榜说明 | view=votes | 非消费指标、计票设计边界 | G7前无投票与票数 |
| 收藏 | view=collection | 当前浏览器的独立v2收藏 | 回到展品 |

两套原型采用同一信息树；A与B的首页构图、地域段落节奏及详情明暗分区不同。URL可以直接分享同一设备上的本地预览位置。

核心三次点击：地区页点地区按钮 → 点包装展签 → 点“查看包装正面”。不要求在狭小省界上精准点按。六件之外的地区显示迁移说明，并提供旧版126份完整档案的入口。

G2只检验视觉与可点击路径。正式六件前台重构、符号热区、双件比较、排序与更多筛选属于G3后续任务；本原型未宣称这些已完成。
