# 两套原型的设计系统

| 设计项 | A 暖白策展 | B 深墨展厅 |
| --- | --- | --- |
| 主要底色 | #F3F0E8暖纸白 | #182528深墨，正文转暖白 |
| 主文字 | #182528 | #F0ECDF；阅读区为深墨 |
| 强调 | #9C4A3E朱砂 | #D3B880旧铜色；阅读区朱砂 |
| 首页构图 | 左侧分行标题、右侧略倾斜烟标展板 | 夜色聚光柜、短标题与直立包装、较低的横向节奏 |
| 地域区节奏 | 纵向标题后并列门票 | 侧边导语加横向小展厅 |
| 详情 | 暖白连续卷轴 | 深色对象区，暖白连续阅读区 |
| 省份卡 | 实际省界轮廓、地区大字、样板数 | 同一真实省界，边框更弱、暗色展台 |
| 烟标卡 | 纸面包装图、底部展签 | 明亮的对象台与暗色展签 |
| 角色卡 | 深色轮廓场，与烟标卡明确区别 | 暗色轮廓场，内容密度保持克制 |

标题使用本机衬线字体栈，正文使用无衬线字体栈；不依赖外部字体网络。可用Noto字体时优先使用，否则回退宋体与微软雅黑。正式阶段可再选择有明确许可的自托管字体。

桌面内容宽度上限1440px，内边距5vw，常规有效内容约1296px；手机边距16px。桌面烟标三列、手机两列；手机角色卡单列，长文与映射都改为单列。重要触控按钮最小44px。手机标题的强调词不拆成孤字。

交互状态：地区按钮用填色和`aria-pressed`标记选择；地图用填色及描边同步；剪影首次按下揭示、再次进入详情；收藏持久化后更新文本和`aria-pressed`；空展厅和未开放计票均有原因与可继续浏览的路径。

常规过渡250–280ms，剪影揭示450ms。`prefers-reduced-motion: reduce`关闭全部过渡，且滚动恢复即时。全部核心操作可点击，不以hover作为唯一触发方式。

不将未知历史写进展签，不使用价格、折扣、商品评分或消费排行榜。原型中的“省界”来自旧版geoBoundaries示意地图，不把装饰曲线伪称为真实山脉。
