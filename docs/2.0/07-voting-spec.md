# 设计投票的阶段边界

G2只提供静态规则说明入口，没有API、计票、访问凭证或公众票数。任何演示页面不得填入假票数。

后续G7拟采用烟标图案与文化记忆偏好，今日、七日和累计分开，日界线为北京时间00:00。每日一票必须由服务端唯一约束与原子写入保证；浏览器本地存储不能代替公众计票控制。

正式实现需说明更新时间、参与人数口径、异常票状态、撤票与复核流程。不得使用口感、购买价值和销量排行作为公开指标。G7还需核验适用规则、运营方式和数据最小化，在负责人决定前不开放真实投票。
